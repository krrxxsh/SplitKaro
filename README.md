# SplitKaro 💸✨
**Split smarter. Settle faster.**

SplitKaro is a premium, minimalist fintech application designed to remove the friction from group expenses. Built with a focus on high-end visual aesthetics and behavioral design, it replaces clunky forms with intent-driven UI patterns. 

Whether you're splitting rent with roommates or managing a weekend trip to Goa, SplitKaro makes tracking and settling balances feel effortless.

## ✨ Features
* **Liquid Glass UI:** A stunning, fully native glassmorphism design system using `expo-blur` that ensures a premium, frosted aesthetic across all devices.
* **Frictionless Entry (Giant Numpad):** Say goodbye to standard keyboards. A custom, full-screen numpad allows for rapid, error-free expense logging.
* **Quick Settle Dashboard:** An intelligent "Action Required" home widget that auto-detects negative balances and provides one-tap payment resolutions.
* **Contact-Driven Groups:** Seamlessly select members from a simulated native contact list instead of manually typing names.
* **Cross-Platform:** Built with React Native & Expo, ensuring buttery smooth 60fps animations on both iOS and Android.

## 🚀 Future Roadmap
We are actively working on turning SplitKaro into a fully autonomous expense manager. Upcoming features include:

* [ ] **AI Receipt Scanner:** Snap a picture of a restaurant bill, and our OCR engine will automatically itemize the receipt and assign costs to individuals.
* [ ] **Payment Screenshot Imports:** Upload a screenshot of a UPI/Bank payment success screen, and SplitKaro will automatically log the expense amount, date, and merchant.
* [ ] **Backend Integration:** Migration to Firebase/Supabase for real-time multiplayer syncing across devices.
* [ ] **Smart Reminders:** Gentle, automated push notifications for pending settlements.

## 🛠 Tech Stack
* **Framework:** React Native / Expo
* **Routing:** Expo Router (File-based routing)
* **Styling:** React Native StyleSheet (Custom Tokens & Typography)
* **Icons:** Ionicons
